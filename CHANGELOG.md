# CHANGELOG

## 1.0.0 (2026-10-11)
- Initial public release as **It's My Bib** by Cheah Pin Chee ([@cheahpc](https://github.com/cheahpc)), MIT licensed. Renamed from "MyBib Portable Backup" (backup envelope magic `mybib-portable-backup` unchanged, so existing backup files still restore; new files are named `its-my-bib-backup-*.json`).
- Detect MyBib + project count, one-button full export as plain JSON via Save dialog, full-tab importer with preview + Backup / Restore-only buttons each with a status pill (Idle / Processing / Done / Cancelled / Error).
- New original archive-motif logo; bundled Google Material Symbols (inline SVG, no CDN).
- Local-only: no Plus bypass, no server calls, no telemetry, no cookie/token access. See DISCLAIMER.md.
